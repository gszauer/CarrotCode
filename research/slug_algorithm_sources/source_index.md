# Slug Algorithm Source Index

This folder contains local research copies used by Research Agent 1.

- `jcgt_slug_paper.pdf`: Eric Lengyel, "GPU-Centered Font Rendering Directly from Glyph Outlines", JCGT 2017. Original URL: https://jcgt.org/published/0006/02/02/paper.pdf
- `SlugPixelShader.hlsl`: Eric Lengyel Slug reference pixel shader. Original URL: https://raw.githubusercontent.com/EricLengyel/Slug/main/SlugPixelShader.hlsl
- `SlugVertexShader.hlsl`: Eric Lengyel Slug reference vertex shader. Original URL: https://raw.githubusercontent.com/EricLengyel/Slug/main/SlugVertexShader.hlsl
- `Slug_README.md`: EricLengyel/Slug README with implementation tips. Original URL: https://raw.githubusercontent.com/EricLengyel/Slug/main/README.md
