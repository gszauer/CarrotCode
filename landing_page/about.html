1 Carrot Code is a minimal text editor written in C++, inspired by lite (https://github.com/rxi/lite).
2 It's cross platform (linux, windows, mac, web), small (<200 KiB), and has some neat features (like syntax highlighting).
3
4 [V1] of carrot code focused on modern C++, OpenGL rendering, and full unicode support.
5 In contrast [V2] is written more C-like, it uses a software renderer,
6 [V2] and embeds [font 8x16] and only displays ascii characters.
